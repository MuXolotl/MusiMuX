# MusiMuX

Десктоп-клиент VK Музыки. Работает без собственных серверов проекта.

## Что умеет

- Вход по логину и паролю — код подтверждения любым способом, который разрешает VK (SMS, push, звонок, почта, аутентификатор), — или по готовому токену
- Несколько аккаунтов: переключение без перезапуска приложения и повторного ввода пароля
- «Моя музыка», альбомы, страницы исполнителей и кураторов
- Вкладки «Недавнее», «Друзья» и «Подписки»: прослушанное, музыка друзей с учётом настроек доступа и подписки на музыкантов и кураторов
- Создание и редактирование плейлистов, добавление треков и фильтры «Все», «Мои» и «Добавленные»
- Главная, Обзор и Рекомендации: персональные подборки, миксы с оценкой «Не нравится», новинки, чарты, жанры
- Один поиск в шапке с областью «Вся музыка» или «Моя музыка», подсказки по мере набора и отключаемая локальная история запросов отдельно для каждого аккаунта
- Ссылки VK, вставленные в поиск: трек, плейлист, альбом, исполнитель, куратор, профиль, сообщество и раздел открываются сразу; по ссылке на трек — окно трека с обложкой, действиями и похожими треками
- Страницы исполнителей: «Микс по артисту», копирование ссылки и переход в VK
- Меню трека: похожие треки, ссылка на трек, альбом с переходом на его страницу и причина, если трек недоступен
- Текст песни из десяти источников с выбором варианта: синхронизированный выбирается сам, строки следуют за треком, перемотка по клику, выравнивание по центру или слева, копирование текста и полноэкранный режим «Сейчас играет»
- Скачивание треков в MP3, а также AAC и FLAC при их доступности у VK; скачивание плейлистов и альбомов в MP3 или лучшем доступном формате, очередь с отменой и повтором, показ скачанных файлов в проводнике; скачанные файлы запоминаются между запусками и повторно не скачиваются, папки загрузок и плейлиста открываются кнопкой «Открыть папку»
- Загрузка собственных MP3 до 200 МБ в «Мою музыку» с очередью, прогрессом, отменой и повтором
- Эквалайзер с предусилением, скорость с опцией сохранения высоты тона, реверберация и кроссфейд; скорость, реверберация и предусилитель — в панели быстрых настроек прямо из плеера и экрана «Сейчас играет»
- Мини-плеер у трея, медиа-клавиши, глобальные сочетания, навигация клавиатурой и боковыми кнопками мыши
- На Windows: трек в системной медиапанели с названием, исполнителем и обложкой; кнопки управления в миниатюре MusiMuX на панели задач; название и значок плеера в микшере громкости
- Трансляция текущего трека в статус — по желанию, выключена по умолчанию
- Автообновления с GitHub Releases (уведомление / автоматически / вручную — на выбор)

Приложение работает без своих серверов: токен, настройки, кеш и скачанные файлы хранятся только на вашем компьютере. При поиске текста приложение параллельно обращается к VK и открытым каталогам текстов; внешним каталогам передаются исполнитель и название трека. Проверка обновлений обращается к GitHub.
