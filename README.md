# MusiMuX

Музыкальный десктоп-клиент. Работает полностью локально — без внешних серверов.

## Что умеет

- Вход по логину и паролю с любым способом 2FA (SMS, push, звонок, почта, аутентификатор) или по токену
- Библиотека, плейлисты, альбомы, страницы исполнителей и кураторов
- Главная и Обзор: персональные подборки, миксы, новинки, чарты, жанры
- Поиск с подсказками по трекам, исполнителям и подборкам
- Текст песни с караоке-режимом и полноэкранный режим «Сейчас играет»
- Скачивание треков, плейлистов и альбомов в MP3 с тегами и обложкой; очередь закачек с лимитом, отменой и повтором
- Эквалайзер и кроссфейд между треками
- Мини-плеер у трея, медиа-клавиши, глобальные сочетания, навигация клавиатурой и боковыми кнопками мыши
- Трансляция текущего трека в статус — по желанию, выключена по умолчанию
- Автообновления с GitHub Releases (уведомление / автоматически / вручную — на выбор)

Приложение работает без своих серверов: токен, настройки, кеш и скачанные файлы хранятся только на вашем компьютере.
