# MusiMuX

Десктоп-клиент VK Музыки. Работает без собственных серверов проекта.

## Что умеет

- Вход по QR-коду через приложение VK на телефоне, по логину и паролю (SMS, push, звонок, почта, аутентификатор) или по готовому токену
- Несколько аккаунтов: переключение в один клик без перезапуска и повторного ввода пароля
- «Моя музыка», альбомы, страницы исполнителей и кураторов
- Вкладки «Недавнее», «Друзья» (с фильтром закрытой музыки) и «Подписки» на музыкантов и кураторов
- Режим «Выбрать» в «Моей музыке» и плейлистах: перестановка треков перетаскиванием, пакетное скачивание и удаление с отменой
- Страница плейлиста и альбома с описанием, поиском внутри списка, липкой мини-шапкой при прокрутке и сводкой по скачанным и FLAC-трекам
- Создание и редактирование плейлистов с обложкой, добавление треков и фильтры «Все», «Мои» и «Добавленные»
- Главная, Обзор и Рекомендации: персональные подборки, миксы с оценкой «Не нравится», новинки, чарты, жанры
- Один поиск в шапке с областью «Везде» или «Моя музыка», подсказки по мере набора и отключаемая локальная история запросов для каждого аккаунта
- Ссылки VK, вставленные в поиск: трек (с окном трека, действиями и похожими), плейлист, альбом, исполнитель, куратор, профиль и сообщество — в том числе по короткому адресу
- Страницы исполнителей: популярное, релизы, клипы, «Микс по артисту», копирование ссылки и переход в VK
- Меню трека: очередь, похожие треки, ссылка на трек, переход к альбому и причина, если трек недоступен
- Текст песни из десяти источников с автовыбором синхронного варианта, перемоткой по клику, выравниванием, копированием и экраном «Сейчас играет»
- Скачивание треков, плейлистов и «Моей музыки» пакетами в MP3, AAC и FLAC с тегами и обложкой; скачанные файлы запоминаются между запусками
- Загрузка собственных MP3 до 200 МБ в «Мою музыку» с очередью, прогрессом, отменой и повтором
- Эквалайзер с предусилением, скорость с сохранением высоты тона, реверберация, кроссфейд и панель быстрых настроек прямо в плеере и «Сейчас играет»
- Мини-плеер у трея, медиа-клавиши, глобальные сочетания, настройка значка добавления в «Мою музыку» и навигация боковыми кнопками мыши
- На Windows: трек в системной медиапанели, кнопки управления в миниатюре на панели задач, название и значок плеера в микшере громкости
- Трансляция текущего трека в статус — по желанию, выключена по умолчанию
- Автообновления с GitHub Releases (уведомление / автоматически / вручную — на выбор)

Приложение работает без своих серверов: токен, настройки, кеш и скачанные файлы хранятся только на вашем компьютере. При поиске текста приложение параллельно обращается к VK и открытым каталогам текстов; внешним каталогам передаются исполнитель и название трека. Проверка обновлений обращается к GitHub.
